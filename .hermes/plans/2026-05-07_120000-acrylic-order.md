# Plan: Fitur Order Acrylic — WCC Oranye Capture

## Goal
Menambah fitur **Order Acrylic** yang berdiri sendiri (tanpa master data kompleks), dengan:
1. Form order: Custom text (ucapan), alamat, tanggal & jam acara, Term & Condition
2. Master data sederhana: hanya **jenis papan acrylic** (hardcoded pilihan, bisa multi-select)
3. Pembayaran: DP + Pelunasan (sama seperti WCC booking)
4. Dashboard gabungan: WCC + Acrylic dalam satu kalender view
5. Total card terpisah (WCC only, Acrylic only) + total gabungan

---

## Current Context

### Existing (WCC Booking)
- **Schema**: `Booking`, `Payment`, `PricePackage`, `EventType`, `AddOn`
- **Dashboard**: Stats cards (total bookings, total revenue, unpaid, completed, pending)
- **Bookings page**: List + Calendar view, filter by status
- **Auth**: BetterAuth (standalone, sudah di-revert dari portal SSO)

### Acrylic Order (NEW)
- Form: static text (ucapan), alamat, tanggal, jam, jenis papan (multi), harga, DP, pelunasan
- Tidak perlu: `EventType`, `PricePackage`, `AddOn`, `BookingEventType`, `PackageEventType`
- Cukup: `AcrylicOrder` + `AcrylicPayment` (mirip pattern `Booking` + `Payment`)

## Proposed Approach

### 1. Schema (Prisma)

**Model baru: `AcrylicOrder`**
```
AcrylicOrder:
  id            String    @id @default(cuid())
  clientName    String
  acrylicText   String    // "Ucapan" full text (multiline)
  address       String
  eventDate     DateTime
  eventTime     String?   // "08:00" — jam acara, optional
  panelTypes    String[]  // array of panel type names, stored as JSON
  totalPrice    Int       // harga total (free input)
  status        AcrylicStatus @default(PENDING)
  notes         String?
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  createdById   String?
  createdBy     User?     @relation(fields: [createdById], references: [id])
  payments      AcrylicPayment[]

AcrylicPayment:
  id              String   @id @default(cuid())
  acrylicOrderId   String
  acrylicOrder    AcrylicOrder @relation(...)
  amount          Int
  note            String?
  paidAt          DateTime @default(now())
  createdAt       DateTime @default(now())

enum AcrylicStatus:
  PENDING
  CONFIRMED
  COMPLETED
  CANCELLED
```

**Model baru: `PanelType`** (master data sederhana)
```
PanelType:
  id          String   @id @default(cuid())
  name        String   // e.g. "Akrilik Graduation"
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
```

## Risks & Tradeoffs

| Risk | Mitigation |
|------|------------|
| `acrylicText` stored as plain string — bisa sangat panjang | Use `Text` type (Prisma), no length limit |
| Multi-panel select — how to store? | Store as `String[]` (PostgreSQL text[]), atau JSON string |
| Calendar unification — complex to merge two data sources | Use shared CalendarView component, pass union type |
| Dashboard stats — double fetch (WCC + acrylic) bisa lambat | Promise.all, add loading states |

## Open Questions — ANSWERED

1. **Auto-complete status**: ✅ otomatis lunas (COMPLETED) saat total payments = totalPrice
2. **Panel types**: ✅ seed aja dulu (5-6 jenis, no settings UI)
3. **Calendar toggle**: ✅ di dashboard juga, unified calendar saja (no toggle)
4. **Acrylic order edit**: ✅ bisa edit full (semua field termasuk teks ucapan)
5. **CreatedBy**: ✅ sama seperti WCC, track user yang bikin

## ⚠️ DATA SAFETY RULES

2. **Jangan pernah DROP kolom/tabel yang ada** — hanya ADD
3. **Selalu konfirmasi dulu** sebelum eksekusi jika涉及到 schema migration
4. Current WCC data (bookings, payments, dll) **HARUS tetap aman**
